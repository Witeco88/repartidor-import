## Actualització a GitHub
1. Obre el repositori de GitHub.
2. Substitueix els fitxers de la versió anterior pels d'aquest paquet.
3. Fes `Commit changes`.
4. Espera que GitHub Pages publiqui el canvi.
5. Si l'iPhone mostra una versió antiga, tanca completament la PWA i torna-la a obrir. El Service Worker és v29 i elimina la caché anterior.
