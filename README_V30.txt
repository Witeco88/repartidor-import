# Repartidor v30 — Usabilitat

Aquesta versió prioritza la facilitat d'ús abans que la densitat d'informació.

## Què canvia
- Import rebut és el primer element visual.
- El mètode de repartiment es pot canviar des de la pantalla principal.
- «Parts iguals» té un selector visible i es conserva.
- Els resultats tenen targetes senzilles amb nom, percentatge i import.
- Afegir persones és immediat i continua limitat a 10.
- Els noms es poden editar.
- Historial, Resum i Ajustos queden separats per reduir soroll visual.
- Navegació inferior compacta.
- Light/Dark mode.
- PWA/offline amb cache v30.

## Publicació
Substitueix els fitxers del repositori de GitHub pels d'aquest paquet i fes Commit changes.
Si l'iPhone mostra una versió anterior, tanca completament la PWA i torna-la a obrir.
